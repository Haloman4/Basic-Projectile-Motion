# Basic-Projectile-Motion
This models some basic equations for projectile motion(i.e. what often appears in high school physics). The user can edit the acceleration equation or the starting velocity, and it puts out velocity and position equations, and roots for the position equation if there are any.
It also takes an array of times, and puts out the corresponding values for position and velocity. The code relies heavily on Numpy and Sympy, so you must install them if your IDE doesn't come with them automatically.
