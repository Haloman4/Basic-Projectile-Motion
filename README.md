# Basic-Projectile-Motion
This models some basic equations for projectile motion(i.e. what often appears in high school physics). Using the Numpy and Sympy libraries, the code lets the user edit the acceleration equation, the starting velocity, the initial height and angle, and the console displays velocity and position equations, and locations where the particle lands on the ground, if there are any.
It also takes an array of times of your choosing, and puts out the corresponding values for position and velocity. The code relies heavily on Numpy and Sympy, so you must install them if your IDE doesn't come with them automatically.
